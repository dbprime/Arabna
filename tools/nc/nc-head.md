# عربنا — دليل الواصل: النصّ الكامل بلغتيه

الملفّات: `js/newcomer-content.js` **(جديد)** · `js/screens/newcomer.js` **(جديد)** ·
`js/data.js` · `js/i18n.js` · `js/app.js` · `styles/app.css`

⚠️ **هذا الملفّ هو الدليل نفسه، لا وصفٌ له.** فيه **17 قسماً · 361 فقرة ·
بالعربيّة والإنجليزيّة**، جاهزةً للنسخ. **وما فيه أُقرَّ كلمةً كلمة** بعد
مراجعة رامي، **ولا يُعاد صياغته ولا يُختصَر ولا يُضاف إليه سطر.**

# 1) ما هو موجود اليوم — ويُستبدَل كلّه

```js
// js/data.js:126 — ثمانية بنود، ونصّها placeholder بشهادة تعليقها
export const NEWCOMER_PARTS = [ { id:'ssn', … }, … ];   // 8
// js/i18n.js:435 و:1987
ncSoon: 'هذا القسم قيد الإعداد — والنصّ الكامل يصل قريباً.'
```

**والتعليق في `data.js` يقول الحقيقة حرفيّاً:**

> **«The copy is a placeholder and says so. Rai writes the real text.»**

**فهذا الملفّ هو ذلك النصّ.** ⚠️ **و`NEWCOMER_PARTS` تُحذَف**، **و`ncSoon`
و`ncFind` وكلّ مفاتيح `ncSsn…` و`ncLicense…` وأخواتها تُحذَف معها** —
لأنّ العنوان صار داخل المحتوى، **ومفتاحٌ لا يستعمله أحد دَينٌ لا فائدة له.**

**ويبقى من القديم أربعة لا غير:** `ncTitle` · `ncSub` · `ncCardTitle` ·
`ncCardSub` · `ncOpen` — وهي بطاقة الرئيسيّة والقائمة، لا الدليل.

# 2) والقاعدة قبل كلّ شيء: **النصّ ليس HTML**

⚠️ **هذه ليست مسألة ذوق.** ما جرى في شريط المموّل (V.04.1) أنّ دالّةً
أعادت `HTML` ومرّ على `esc()` **فطُبع الوسم كلاماً في أهمّ شاشة عندنا.**
**والدليل سبع عشرة صفحة وفيها 86 رابطاً و41 هاتفاً** — **فلو كان نصّه
`HTML` لعاد العطل، لا احتمالاً بل حتماً.**

**فالنصّ يُخزَّن بمفردات ثمانٍ، ولا تاسعة لها:**

```js
['p',     'فقرة']
['h',     'عنوان داخل القسم']
['ul',    'بند', 'بند', 'بند']
['rows',  ['يمين','يسار'], ['يمين','يسار']]
['warn',  'صندوق مُبرَز']
['alert', 'صندوق تحذير']
['do',    'سطر: ماذا تكتب، وماذا يظهر لك']
['tool',  'flood', 'النصّ الذي يحلّ محلّها إن لم تعمل']
```

⚠️ **والمفردتان الجديدتان اثنتان لا أكثر، ولكلٍّ سببها:**

**`do` — وسببها قاعدتك.** كلّ رابطٍ يُطلب فيه بحث يتبعه سطر `do` يقول
**ماذا يكتب المستخدم وأيّ جوابٍ ينتظره** — **ولا يُترَك رابطٌ عارياً يفتح
صفحةً لا يعرف صاحبها ماذا يفعل فيها.**

**`tool` — وهي الوحيدة التي ترسم أكثر من نصّ**، وهي أداة الفيضان في القسم
التاسع. ⚠️ **ووسيطها الثاني ليس زينة: هو النصّ الذي يُطبَع مكانها إن لم
تعمل الأداة** — في بناءٍ قديم، أو حين يرفض المتصفّح الطلب. **فالمفردة التي
لا نعرفها تسقط إلى نصٍّ مفيد، لا إلى فراغ.**

⚠️ **وقاعدة رامي على المحتوى:** **كلّ سطرٍ يقول «ابحث» أو «تحقّق» يحمل
معه الموقع نفسه.** ولا يُكتب «ابحث عن تقييم المدرسة» — يُكتب **«افتح
`txschools.gov` واكتب العنوان»**. ⚠️ **ومن قيل له ابحث ولم يُقَل له أين،
يفتح محرّك بحث فيصل إلى موقعٍ يبيعه تقريراً بتسعة وعشرين دولاراً.**

**وداخل النصّ ثلاث علامات، ولا رابعة:**

```
**نصّ**              عريض
[الظاهر](الرابط)     رابط — و https:// أو tel: أو mailto: فقط
`نصّ`                يُعرَض من اليسار، معزولاً عن اتّجاه الفقرة
```

⚠️ **وثلاثتها تُطبَّق بعد `esc()` لا قبلها**، **ورابطٌ ببروتوكول غير
الثلاثة يُطبَع نصّاً ولا يصير رابطاً** — فحتى لو دخل نصٌّ من مكانٍ آخر
يوماً ما، **لا يستطيع أن يفتح `javascript:` ولا أن يحقن وسماً.**

```js
// js/screens/newcomer.js — الراسم، وهو السطح الوحيد الذي يحوّل نصّاً إلى HTML
const SAFE = /^(https:\/\/|tel:\+|mailto:)/;

function inline(s) {
  return esc(s)                                             // 1) الهروب أوّلاً، دائماً
    .replace(/\[([^\]]+)\]\(([^)]+)\)/g, (m, txt, url) =>
      SAFE.test(url)
        ? `<a class="nc-a" href="${url}"${url.startsWith('https:') ? ' target="_blank" rel="noopener noreferrer"' : ''} dir="ltr">${txt}</a>`
        : txt)                                              // 2) وما ليس آمناً يبقى نصّاً
    .replace(/\*\*([^*]+)\*\*/g, '<b>$1</b>')
    .replace(/`([^`]+)`/g, '<span class="ltr">$1</span>')
    .replace(/\n/g, '<br>');
}
```

```css
/* styles/app.css — كلّ ما يحتاجه الدليل، ولا كلاس خارج هذه القائمة */
```

⚠️ **و`.ltr` هي قاعدة الهاتف نفسها المكتوبة في `CLAUDE.md`** — الأرقام
والعناوين اللاتينيّة تنقلب داخل فقرة عربيّة، **و`unicode-bidi: isolate`
وحدها تمنع ذلك.** **وهي هنا لكلّ نصّ لاتينيّ لا للهاتف فقط.**

⚠️ **والمتغيّرات كلّها موجودة في البرنامج** — `--gold` و`--muted` و`--line`
و`--green-bg` و`--danger-bg` وأخواتها. **فلا لون جديد، ولا متغيّر جديد،
والوضع الفاتح يعمل من نفسه.**

# 3) والراسم — دالّة واحدة، ولا شاشة تكتب راسمها

```js
function blockHtml(b) {
  switch (b[0]) {
    case 'p':     return `<p>${inline(b[1])}</p>`;
    case 'h':     return `<h4 class="nc-h">${inline(b[1])}</h4>`;
    case 'warn':  return `<div class="nc-warn">${inline(b[1])}</div>`;
    case 'alert': return `<div class="nc-alert">${inline(b[1])}</div>`;
    case 'do':    return `<p class="nc-do">${inline(b[1])}</p>`;
    case 'tool':  return TOOLS[b[1]] ? TOOLS[b[1]]() : `<p>${inline(b[2] || '')}</p>`;
    case 'ul':    return `<ul class="nc-ul">${b.slice(1).map(x => `<li>${inline(x)}</li>`).join('')}</ul>`;
    case 'rows':  return `<div class="nc-rows">${b.slice(1)
                    .map(r => `<div><span>${inline(r[0])}</span><span>${inline(r[1])}</span></div>`)
                    .join('')}</div>`;
    default:      return '';        // مفردة لا نعرفها لا تُطبَع، ولا تكسر الصفحة
  }
}
```

⚠️ **و`default` يعيد فراغاً عمداً.** يوم نضيف مفردة سابعة، **البناء
القديم لا ينهار عليها** — يتجاهلها ويكمل. **وهذا أرخص من نسخةٍ تتعطّل عند
قارئٍ لم يحدّث.**

# 4) زرّ اللغة — وهو طلبك

```
في رأس الدليل، بجانب العنوان:

   دليل الواصل الجديد                    [ Read in English ]
   Newcomer's guide                      [ اقرأ بالعربيّة ]
```

```js
S.state.ncLang   //  'ar' | 'en'  — ويبدأ من لغة البرنامج، ثمّ يستقلّ عنها
```

⚠️ **والزرّ يُكتب باللغة التي يذهب إليها، لا باللغة التي أنت فيها.** من لا
يقرأ العربيّة **لن يفهم زرّاً مكتوباً بالعربيّة يقول إنّه ينقله إلى
الإنجليزيّة** — **فالزرّ نفسه أوّل ما يُقرأ منه.**

⚠️ **ويبدّل الدليل وحده.** البرنامج يبقى على لغته: القائمة والدليل
والسوق والرئيسيّة **لا يتحرّك فيها شيء.** **والسبب:** الأب يقرأ البرنامج
بالعربيّة ويعطي الهاتف لابنه ليقرأ قسم المدرسة بالإنجليزيّة، **ثمّ
يستردّه ولا يجد برنامجه قد انقلب.**

⚠️ **والاختيار يُحفَظ** في `arabna.v1` مع بقيّة الحالة، **ويبقى بعد
الإغلاق** — فمن اختار مرّة لا يُسأل ثانية.

⚠️ **واتّجاه الصفحة يتبع `ncLang` لا لغة البرنامج:** `dir="rtl"`
للعربيّة و`dir="ltr"` للإنجليزيّة، **على حاوية الدليل وحدها** — لا على
`<html>`، وإلّا انقلب البرنامج كلّه.

# 5) والنشاط ذو الصلة آخر كلّ قسم — وهو قرارك

**كلّ قسم يحمل فئته، لا اسم محلّ:**

```js
{ id:'ssn', icon:'file', cat:'community' }
{ id:'doctor', icon:'stethoscope', cat:'doctors', attrs:'arabicSpoken' }
```

⚠️ **ولا يُكتب اسم نشاطٍ في المحتوى أبداً.** المحلّ يغلق، والاشتراك
ينتهي، **والنصّ يبقى** — فيصير الدليل يوصي بمحلٍّ مغلق. **الفئة تُكتب،
والنشاط يُختار لحظةَ العرض.**

**والاختيار بالأولويّة التي وضعتَها:**

```
مشترك      →  من نشاطات الفئة، ويُكتب فوقه: «إعلان — نشاط مشترك في القسم»
مميّز      →  إن لم يوجد مشترك
مجّانيّ     →  إن لم يوجد الاثنان — بلا شارة وبلا إطار ذهبيّ،
              ويُكتب فوقه: «من الدليل — لا يوجد مشترك في هذا القسم بعد»
لا شيء     →  إن كانت الفئة فارغة تماماً: لا مساحة ولا عنوان ولا فراغ
```

⚠️ **والحالة الرابعة ليست تفصيلاً** — هي قاعدة الملفّ (ب) نفسها: **بابٌ
فارغ أسوأ من لا باب.**

⚠️ **وتحته صفّ ثابت:** «كلّ {الفئة} في الدليل ←» — **فمن لم يعجبه
المعروض يجد القائمة كلّها**، ولا ينتهي القسم عند إعلان.

## والسطر الذي يُقال للمشترك

**في شاشة الاشتراك، تحت المزايا:**

> **وإعلانك يظهر في دليل الواصل الجديد** ضمن القسم الذي يخصّ نشاطك —
> **وهذا ضمن الاشتراك، لا يُباع وحده.**

## والمشاركة — وهي قرار رامي

⚠️ **ودليل الواصل أكثر ما يُشارَك في البرنامج كلّه.** من قرأ فقرة
الفيضان يعرف ثلاثة يحتاجونها **الليلة**، **ولا يشارك خمسةً وستّين صفحة
ليصل صاحبه إلى فقرة.**

**فلكلّ قسم رابطه:**

```js
// js/app.js — المسار يقبل معرّفاً
{ re: /^#\/newcomer(?:\/(.+))?$/, screen: NewcomerScreen, nav: 'directory' }
```

```
#/newcomer          الدليل كلّه
#/newcomer/flood    الدليل نفسه، منزلقاً إلى القسم
```

```js
// وزرّ المشاركة يستعمل shareItem الموجودة (ui.js:1731) بلا تغيير
shareItem(sec[lang].t, location.origin + location.pathname + '#/newcomer/' + sec.id);
```

⚠️ **ولا تُفتَح شاشة لقسمٍ وحده.** الرابط يفتح **الدليل كلّه منزلقاً إلى
موضعه** — **فمن وصله رابط الفيضان يجد تحته السكن والإيجار، ويقرأ ما لم
يكن يبحث عنه.** **وشاشةٌ لقسمٍ واحد تغلق هذا الباب.**

⚠️ **و`shareItem` مبنيّة وتعمل** — تستعمل مشاركة النظام إن وُجدت، ثمّ
النسخ، **ثمّ تعرض الرابط نفسه محدَّداً إن فشل الاثنان.** ولا يُكتب لها
بديل.

⚠️ **والقسم يحمل `id="nc-{id}"`**، والانزلاق `scrollIntoView` مرّةً عند
الفتح — **ولا يُعاد كلّما تغيّرت اللغة.**

# 7) وزرّ التبليغ — كما في الملفّ (ز)

**في آخر كلّ قسم، أيقونة صغيرة لا زرّ عريض:**

```js
openReportSheet('guide', sec.id, sec[lang].t);
```

**وأسبابه هي أسباب «ما ننزله نحن»:**

```
معلومة غير صحيحة
انتهت أو أُلغيت
مسيء أو غير مناسب
غير ذلك — سطر واحد
```

⚠️ **وهذا الدليل أولى شيء بالزرّ:** فيه أرقام ومهل وأسعار، **وأوّل من
يكتشف أنّ رقماً تغيّر هو من اتّصل به** — لا نحن.

# 9) أداة الفيضان — وهي الجواب داخل البرنامج

⚠️ **وهذا قرار رامي، وسببه مكتوب:** الروابط التي لا تعطي جواباً مباشراً
تُشتّت، **ومن فتح خريطةً حكوميّةً بالإنجليزيّة لا يعرف ماذا يفعل فيها.**
**فالفيضان وحده له جهة رسميّة تردّ آليّاً — فيُجلب جوابه إلى الشاشة.
والباقي يبقى رابطاً، ولكن لا يبقى عارياً: تحته سطر `do`.**

## أوّلاً: السطر الذي يُقرأ قبل أوّل استعمال

```
📍 اعرف الآن — بلا أن تخرج من البرنامج

  [ اكتب عنوان البيت…                    ]  [ افحص ]

  العنوان يذهب إلى خريطة FEMA الرسميّة لجلب الجواب — ولا يُخزَّن.
```

⚠️ **وهذه أوّل مرّة يرسل فيها البرنامج عنوان بيتٍ إلى جهة خارجيّة**، فالسطر
واجب، **ويُكتب تحت الخانة قبل الكتابة لا بعدها.** وأربعة تُكتب هنا مرّة
وتُنفَّذ دائماً:

```
ولا حفظ      لا في البرنامج ولا في الجهاز — ولا حتّى آخر عنوانٍ بحث فيه
ولا حساب     الزائر يستعملها بلا تسجيل
ولا اسم      العنوان وحده: بلا اسمٍ ولا رقمٍ ولا حساب
ولا سجلّ      لا يُرسَل إلى خادمنا، ولا يمرّ به أصلاً
```

## ثانياً: الجواب — حالتان لا ثالثة

**خارج منطقة الخطر العالي:**

```
✓  خارج منطقة الفيضان عالية الخطر        [ Zone X ]

   خطر متوسّط أو منخفض. والتأمين على الفيضان غير إلزاميّ هنا —
   لكنّه ممكن، وثلث مطالبات الفيضان تأتي من خارج مناطق الخطر العالي.

   ← تأكيد على خريطة FEMA الرسميّة
     العنوان يُكتب في خانة «Enter an address, place, or coordinates»
```

**داخل منطقة الخطر العالي:**

```
⚠  داخل منطقة فيضان عالية الخطر          [ Zone AE ]

   احتمال الفيضان 1% في كلّ سنة — أي مرّة كلّ مئة سنة في المتوسّط،
   لا مرّة في العمر. والتأمين على الفيضان إلزاميّ مع أيّ قرض عقاريّ
   من بنكٍ خاضع للرقابة.

   ← اسأل المؤجّر: هل غرق البيت في آخر خمس سنوات؟
     القانون يوجب جواباً مكتوباً وموقَّعاً من الطرفين — ولا تقبل جواباً شفويّاً
   ← وتأمين المستأجر لا يغطّي الفيضان
     وثيقة منفصلة، وتبدأ بعد 30 يوماً من الشراء
   ← تأكيد على خريطة FEMA الرسميّة
```

⚠️ **والقاعدة: `A` أو `V` في أوّل الحرف ← عالية الخطر. وما عداها ← الحالة
الأولى.** ولا تُترجَم كلمة `Zone` ولا حرفها: **هي ما سيقوله له البنك
وشركة التأمين بالحرف نفسه.**

⚠️ **والرابط يأتي بعد الجواب لا قبله** — تأكيداً، لا مهمّةً يعملها.

## ثالثاً: الطريق — خطوتان، وكلتاهما بلا مفتاح

```
1) العنوان ← نقطة       geocoding.geo.census.gov   (مكتب الإحصاء — بلا مفتاح)
2) النقطة ← الحرف       hazards.fema.gov           (خدمة NFHL العامّة)
```

⚠️ **ولا مكتبة جديدة، ولا حزمة، ولا مفتاح، ولا حساب** — طلبان `fetch`
ونتيجتهما `JSON`. **وطبقة الفيضان في خدمة `NFHL` تُقرأ من قائمة طبقات
الخدمة نفسها وقت التنفيذ، ولا يُكتب رقمها هنا حفظاً**: المطلوب الطبقة
التي حقلها `FLD_ZONE`.

```js
// js/screens/newcomer.js — ولا تكتب هذه الدالّة في ملفّ المحتوى
const TOOLS = { flood: floodTool };

const HIGH = /^(A|V)/;                 // الحرف الأوّل وحده يقرّر

async function floodZone(address) {
  const g = await fetch('https://geocoding.geo.census.gov/geocoder/locations/'
      + 'onelineaddress?benchmark=Public_AR_Current&format=json&address='
      + encodeURIComponent(address)).then(r => r.json());
  const m = g.result?.addressMatches?.[0];
  if (!m) return null;                                    // عنوان لم يُعرَف
  const { x, y } = m.coordinates;
  const f = await fetch(NFHL_QUERY(x, y)).then(r => r.json());
  return f.features?.[0]?.attributes?.FLD_ZONE || null;   // ولا منطقة مرسومة
}
```

⚠️ **وثلاث حالاتٍ لا اثنتان.** الثالثة: **عنوانٌ لم يُعرَف، أو نقطةٌ لا
منطقة مرسومة عليها.** ونصّها: **«ما وصلنا جواباً لهذا العنوان — جرّب
كتابته كاملاً مع الرمز البريديّ، أو أكّده على خريطة `FEMA`»**، ومعه
الرابط. ⚠️ **ولا يُقال «خارج المنطقة» لعنوانٍ لم يُعرَف** — **صمت الخدمة
ليس جواباً بالسلامة، وهذه هي القاعدة نفسها التي كتبناها عن `har.com`.**

## رابعاً: شرطان — وإن سقط أحدهما لا تُشحَن الأداة

⚠️ **وهذا أهمّ ما في الملفّ، فاقرأه قبل أن تكتب سطراً:**

```
الشرط الأوّل   أن تسمح الجهتان بالطلب من متصفّح (CORS) — وهذا لم أستطع
              قياسه من عندي، فشبكتي محجوبة. يُقاس بأوّل طلبٍ من متصفّح حقيقيّ.
الشرط الثاني   أن تُضاف الجهتان إلى connect-src في النسختين — وهذا شرطٌ
              على البرنامج لا عليهما.
```

```
Content-Security-Policy … connect-src 'self'
    https://geocoding.geo.census.gov
    https://hazards.fema.gov
```

⚠️ **والإضافة في النسختين معاً:** `index.html` و`index-single-file.html`.
**ولا يُلمَس `script-src` ولا غيره.**

⚠️ **وإن رفض المتصفّح أحد الطلبين، أو تأخّر، أو ردّ بخطأ:** **تختفي
الخانة ويُطبَع مكانها نصّ الوسيط الثاني** — سطرٌ فيه رابط `FEMA` كما هو
اليوم. **ولا رسالة خطأ، ولا صندوق أحمر، ولا خانةٌ تبتلع ما يُكتب فيها ولا
تردّ.** **وأداةٌ لا تعمل تُحذَف من الشاشة، لا تُترَك معطّلة.**

⚠️ **وقياس الشرط الأوّل أوّل عمل، قبل الواجهة:** طلبان من المتصفّح
بعنوانٍ واحد. **إن نجحا فالباقي ساعة. وإن فشل أحدهما فالقرار عندي، لا
عندك: تكتب لي ما ردّ به المتصفّح حرفيّاً، وأنا أقرّر.**
