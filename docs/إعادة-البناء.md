# عربنا — إعادة البناء من الصفر

**هذا الملفّ يجيب سؤالاً واحداً: لو ضاع كلّ شيء، كيف يرجع البرنامج؟**

---

## 1) وما الذي يمكن أن يضيع أصلاً

```
Vercel               الواجهة لا المخزن — ينشر من هذا المستودع
                     فسقوطه لا يُفقد سطراً · يُعاد الربط ويعود
هذا المستودع          المخزن الحقيقيّ — الشيفرة والبيانات ونصّ الدليل ومصدره
جهاز القارئ           لا خادم بعد · وحالة كلّ قارئ في localStorage عنده
```

⚠️ **ولا توجد اليوم بياناتُ خادمٍ تُفقَد** — لا حسابات ولا اشتراكات ولا
صور على خادم. **وهذا يتغيّر يوم تنزل دفعة السيرفر**، وعندها تصير للنسخ
الاحتياطيّ خطّةٌ أخرى تُكتَب هنا.

---

## 2) إرجاع البرنامج — ثلاث خطوات

```
1   git clone <عنوان المستودع>
2   Vercel ← مشروع جديد ← استورد المستودع
    ولا أمر بناء ولا مجلّد إخراج — البرنامج بلا خطوة بناء أصلاً
3   انتهى
```

⚠️ **والمستودع يحمل كلّ نسخةٍ من أوّل يوم، لا آخر واحدة.** فالرجوع إلى
ما قبل عطلٍ هو `git checkout` لا إعادة كتابة.

**والنسخة الملفّ-الواحد تُبنى بأمرٍ واحد:**

```
python3 tools/build_single.py        →  index-single-file.html
```

---

## 3) إرجاع دليل الواصل

**`js/newcomer-content.js` مُولَّد.** ومصدره ومولّده في `tools/nc/`،
والخطوات في `tools/nc/اقرأني.md`. ⚠️ **ولا يُعدَّل المولَّد بيد.**

---

## 4) وما يبقى خارج هذا المستودع

```
ملفّات لم تُرسَل بعد        عند رامي — وتدخل هنا واحداً واحداً
شهادات المتاجر والدومين     عند رامي · ولا تُكتَب في شيفرة أبداً
كلمة مرور اللوحة            يضعها رامي بيده · بقرار أمنيّ
```

⚠️ **ولا مفتاح ولا كلمة مرور ولا `service_role` في هذا المستودع، أبداً**
— مكانها متغيّرات بيئة الخادم وحدها.

---

## 5) والفحص بعد أيّ إرجاع

```
python3 -m http.server 8099        # من جذر المستودع
tools/audit/quick.sh               # 62 ثانية — البوّابة
tools/e2e/run.sh                   # ~23 دقيقة — الشبكة كاملة
node tools/nc/check-render.mjs     # الدليل — 23 فحصاً
```
